# Currency Exchange Calculator

A simple currency exchange calculator built using HTML, CSS and JavaScript.

## Features

- Convert between GBP, USD, EUR and JPY
- User input validation
- Currency selection
- Automatic conversion calculation
- Simple responsive interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

Through this project I practised:

- JavaScript functions
- Variables and constants
- Objects
- DOM manipulation
- User input validation
- Mathematical calculations
- HTML forms
- CSS styling
